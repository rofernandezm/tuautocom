### 5. ✅ VehicleService Integrado con MongoDB

**Archivo modificado**: `tuautocom.UI/js/services/vehicleService.js`

**Cambios principales**:

1. **Import de apiClient**:
```javascript
import { apiClient } from './apiClient.js';
```

2. **Método de mapeo** para transformar datos de backend a frontend:
```javascript
_mapVehicle(vehicle) {
  return {
    id: vehicle._id,              // MongoDB ObjectId
    title: vehicle.title,
    description: vehicle.description,
    category: vehicle.category,
    brand: vehicle.brand,
    model: vehicle.model,
    year: vehicle.year,
    price: vehicle.price,
    mileage: vehicle.mileage || 0,
    fuel: vehicle.specs?.fuel || 'N/A',
    transmission: vehicle.specs?.transmission || 'N/A',
    condition: vehicle.condition?.use || 'N/A',
    image: vehicle.images?.[0] || 'placeholder',
    images: vehicle.images || [],
    badge: vehicle.condition?.use === 'new' 
      ? { text: 'Nuevo' } 
      : vehicle.price < 25000 
        ? { text: 'Económico' } 
        : null
  };
}
```

3. **Métodos CRUD conectados**:

```javascript
// Obtener todos (con fallback a mock)
async getAll() {
  try {
    const vehicles = await apiClient.get('/vehicles');
    return vehicles.map(v => this._mapVehicle(v));
  } catch (error) {
    console.error('⚠️ Error, usando mock data:', error);
    return this.mockVehicles; // Fallback
  }
}

// Crear
async create(vehicleData) {
  const created = await apiClient.post('/vehicles', vehicleData);
  return this._mapVehicle(created);
}

// Actualizar
async update(id, vehicleData) {
  const updated = await apiClient.put(`/vehicles/${id}`, vehicleData);
  return this._mapVehicle(updated);
}

// Eliminar
async delete(id) {
  await apiClient.delete(`/vehicles/${id}`);
  return true;
}
```

**Fallback strategy**:
- Si API no disponible → Usa datos mock (2 vehículos de ejemplo)
- Permite desarrollo offline
- Degrada gracefully

## 🎓 Aprendizajes y Decisiones Técnicas

### 1. Arquitectura de Puertos Separados

**Contexto**: Se debatió entre mismo puerto vs puertos diferentes

**Decisión**: Puertos separados (8000 frontend, 8001 backend)

**Razones**:
- Proyectos se deployarán independientemente
- Backend puede servir múltiples frontends
- Escalabilidad futura
- Desarrollo paralelo posible

**Trade-off**: Requiere configuración CORS adicional

### 2. Fallback a Mock Data

**Implementación**: `vehicleService.getAll()` tiene try/catch con fallback

**Ventajas**:
- Desarrollo offline posible
- Degrada gracefully si API falla
- UX no se rompe completamente

**Desventajas**:
- Puede ocultar errores de configuración
- Datos mock pueden quedar desactualizados

### 3. Singleton Pattern en Servicios

**Patrón usado**:
```javascript
class VehicleService { }
export const vehicleService = new VehicleService();
```

**Ventajas**:
- Una sola instancia en toda la aplicación
- Estado compartido (si necesario)
- Imports consistentes

### 4. Mapeo de Datos (Backend → Frontend)

**Por qué necesario**:
- MongoDB usa `_id`, frontend espera `id`
- Backend estructura en `specs.fuel`, frontend espera `fuel` directo
- Badges se calculan dinámicamente

**Método `_mapVehicle()`**:
- Centraliza transformación
- Un solo lugar para mantener
- Evita inconsistencias

### 5. Loading States en Formularios

**Implementación**:
```javascript
submitBtn.disabled = true;
submitBtn.textContent = 'Guardando...';
// ... await API call
submitBtn.disabled = false;
submitBtn.textContent = 'Guardar';
```

**Por qué importante**:
- Evita doble-submit
- Feedback visual al usuario
- Mejor UX

## 🐛 Problemas Encontrados y Soluciones

### Problema 1: IP No Autorizada en MongoDB Atlas

**Error**:
```
Could not connect to any servers in your MongoDB Atlas cluster.
One common reason is that you're trying to access the database 
from an IP that isn't whitelisted.
```

**Solución**:
1. Ir a MongoDB Atlas → Security → Network Access
2. Add IP Address → Add Current IP Address
3. Esperar 1-2 minutos para propagación
4. Reintentar conexión

### Problema 2: Opciones Deprecadas en Mongoose

**Warning**:
```
useNewUrlParser is a deprecated option
useUnifiedTopology is a deprecated option
```

**Solución**:
Actualizar `backend/src/config/db.js`:
```javascript
// Antes
await mongoose.connect(uri, {
  useNewUrlParser: true,
  useUnifiedTopology: true,
});

// Después (Mongoose 6.0+)
await mongoose.connect(uri);
```

### Problema 3: Backend No Respondía

**Síntoma**: `curl http://localhost:8001/api/vehicles` → Exit code 7

**Causa**: Proceso nodemon no estaba corriendo

**Solución**:
```bash
cd backend && pnpm run dev
```

### Problema 4: CORS Errors (Prevención)

**Configuración preventiva** en `backend/src/app.js`:
```javascript
app.use(cors({
  origin: 'http://localhost:8000',
  credentials: true
}));
```

Sin esto, navegador bloquearía todas las peticiones cross-origin.
